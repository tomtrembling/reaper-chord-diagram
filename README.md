# T2 Claude Code starter project

A claude code starter project with the workflow described in the AIHero Engineer Workshop 2026. (https://www.aihero.dev/ai-engineer-workshop-2026~dwnll) 
Includes "Ralph" worker and Skills:
- grill-me
- improve-codebase-architecture
- prd-to-issues
- tdd
- write-a-prd

## Prerequisites

- [Node.js](https://nodejs.org/) v22+
- [npm](https://www.npmjs.com/) v10+
- [Claude Code](https://docs.anthropic.com/en/docs/claude-code) CLI installed
- A Claude Pro or Max subscription

## Getting Started
Planning: 
- Place initial brief into starter-brief.md
- Start planning using /grill-me skill to stress-test vague requirements 
- Use /write-a-prd to produce structured PRD (Product Requirements Document)
- Use /prd-to-issues to break work into thin, vertical "tracer bullet" slices that an agent can pick up independently.

Execution:
- Run the AI agent (Ralph) workflow for HITL (human-in-the-loop) or AFK (Autonomous) with TDD (Test Driven Development)
